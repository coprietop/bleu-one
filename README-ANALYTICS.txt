Se añadió el script oficial de Vercel Web Analytics al index.html:
<script defer src="/_vercel/insights/script.js"></script>

Después de subir esta versión:
1. En Vercel, abre Analytics y asegúrate de que Web Analytics esté habilitado.
2. Despliega esta versión a producción.
3. Visita y navega la app publicada.
4. Los primeros datos pueden tardar unos segundos o minutos en aparecer.

No se agregó Google Analytics ni cookies de terceros.
